# PawNote frontend

Expo (React Native Web). Scaffold lands in Phase 1.3.

## Environment

1. Copy [`.env.example`](.env.example) → [`.env`](.env) if needed (repo includes an empty `.env` template).
2. Use **Supabase Project URL** + **anon / publishable key** only.

Run (after Phase 1.3):

```bash
cd frontend
npm install
npx expo start --web
```
