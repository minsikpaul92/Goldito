Goldito Design Sync

Each ticket comes from its workbench page. Push to Figma builds or updates its section on the “Tickets” page (created the first time): the decided frames, built from the ticket's own components, and the spec. Edit a component there and every frame follows; a push update keeps your edits. Submit for review marks it In review and writes the comment for the GitHub issue.

One page for the devs: the app tabs plus every decided or proposed feature (Moments, words, intro, UX calls, pet tone, delights), each marked decided or proposal, with its frames and notes. Run Screens first so the app tabs are there.

GitHub posting (optional)

Without a token, copy the comment and paste it on the issue. With a fine-grained token (repo minsikpaul92/Goldito, Issues: read and write), “Post to GitHub” adds it for you. The token stays in this Figma app on your computer.
