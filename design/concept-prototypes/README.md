# Goldito design site

One site for all of Goldito's design work: the Draft (the design target, playable in three looks), the step-by-step flows for older owners, the brand, and the plan to the Oct 30 submission. Prototype only: no real accounts, AI, payments or locations.

Live copy: https://mooque-dev.github.io/goldito-design/ (updated when Mook says "push").

## Pages

| Page | What it's for |
| :--- | :--- |
| `index.html` · **Overview** | Start here: countdown, the three looks, where each stage is in the app, every README promise (Play · Figma · README), what we've built |
| `prototype.html` · **Prototype** | Every screen: today's app next to the Draft, with notes and links. Deep links: `#<screen>/<look>`, e.g. `#owner-snap/all`, `#stage-3/d` |
| `steps.html` · **Step by step** | Booking request, care request, Meet & Greet and checkout as one question per screen. Thumbnails, keys (← → 1–4 L D), deep links `#care-3` |
| `brand.html` · **Brand** | Logo directions and icon set, diary decoration, color, type, decisions D2–D6, the rules for when things go wrong |
| `plan.html` · **Plan** | Decisions waiting, where each area stands, the Oct 15–30 schedule, who does what, the design log |

## How it's built

- **`screens.js` is the one list** behind Prototype and Overview: every screen (status in the app, notes in EN/KO, Figma node, README anchor, phase docs) and every README promise (`GOLDITO_FEATURES`). Change statuses here; the pages follow.
- **The stay (`pawnote-concept-{b,c,d}-*.html`)** is one shared journey (`journey/*.js`, `journey/*.css`) inlined into each look by `python3 journey/build.py`. Expressive (`d`) is generated from Balanced (`c`) + `journey/expressive-layer.html`: edit `journey/`, never the inlined copy. Icons are inlined from `journey/icons.js` (Lucide + Pixelarticons), so the pages work offline and inside an artifact.
- **The app's tab screens (`redesign/app.html`)** are generated by `python3 redesign/build_app.py` from `redesign/index.html` (Balanced and Playful phones, with notes) and `redesign/expressive.html` (Expressive layouts). Tabs match the app: Home · Bookings · Feed · Diary · Snap, plus Settings and What's New.
- **Site chrome:** `nav.js` (one bar, five tabs, EN / 한국어 remembered per browser) and `ds.css` (design-system tokens; Fredoka for site headings only, the app uses the system font, D6).
- **Assets:** `assets/overview/` (gallery shots), `assets/brand/` (logo files at web sizes, from `design/brand/`), `redesign/img`, `redesign/live` (Oct 5 captures of the hosted app).

## Run it

Serve this folder (no build step for viewing): `python3 -m http.server 4001`, then open http://localhost:4001/. The `pawnote-concepts` entry in `.claude/launch.json` does the same with no-cache headers.

## Check it

Playwright scripts in `~/Claude/pawnote/.claude/tools/proto-tests/` (need the server on :4001):

- `walk.mjs` walks the whole stay ① → ⑤ in Balanced, Playful and Expressive by clicking only (the total must stay $268.13).
- `audit.mjs` runs axe (WCAG A/AA) and an overflow check on every page and the new tab screens, desktop and phone, light and dark.
- `links.mjs` checks that every internal link and asset resolves.

## Conventions

- Cast (README demo path): owner **Robert**, sitter **Chloe**, pets **Max** (dog, allergic to chicken) and **Mochi** (cat). Thanksgiving stay Oct 9–12, $268.13 CAD.
- Stage names are the README's: Inquiry · Meet & Greet · Booking · Care & Pet Transit · Completion. Dates read "Oct 9–12".
- Product copy is English (D1); notes and site text are EN + KO.
- Anything the sitter does in the Draft is a dashed **DEMO** control or a "Chloe's phone" panel.
