# PawNote P0 — Phase 가이드

각 Phase는 **Goal → 범위 → 작업 → DoD → 산출물** 순으로 정리되어 있습니다.  
AI(Cursor) 프롬프트 원문은 [P0-ai-prompt-playbook.ko.md](../P0-ai-prompt-playbook.ko.md)를 참고하세요.

## 의존 관계

```
00 → 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10
                              ↘ 07,08,09 는 07.1(Nebius) 이후 병렬 가능
```
