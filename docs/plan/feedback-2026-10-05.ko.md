### 자동 저장 제안
- **줄 단위 자동 저장**: 줄을 완성하면 바로 저장하고 줄 옆에 "Saved ✓"가 잠깐 보임 (Notion/Google Docs 방식). Save 버튼이 없어짐.
- **삭제는 "Undo" 스낵바**: 지우면 즉시 반영하되 8초 동안 "Deleted · Undo"를 보여 줌 — 자동 저장의 가장 큰 위험(실수로 지움)을 막음.
- **저장 상태 표시**: 화면 위에 "All changes saved" / 네트워크가 끊기면 "Saving…" → 실패 시 빨간 팝업(남는 팝업)으로 알림.
- **돌보는 중에는 자동 저장 안 함**: 요청으로 보내고 시터가 승인해야 반영 (A8). 그래서 모드가 두 개: 미리 쓰기(자동 저장) / 돌보는 중(요청 → 승인).

### 4·5번 설명 (제 시나리오 번호였습니다)
- **4번**: AI가 만든 체크리스트 화면에서 ① 이름 한 줄을 고치고 ② 시간 칸을 눌러 휠로 바꾸고 ③ 카드 하나의 **Remove**를 누르고 ④ Heads-up 칩의 ✕를 누르고 새 Heads-up을 입력해 추가한 다음 **Save checklist**를 누르는 것.
- **5번**: 저장 후 펫 화면으로 돌아왔을 때 **Care tasks 목록**에 방금 저장한 할 일이, 맨 아래 **Heads-up 칸**에 Heads-up이 보이는지 확인하는 것.
→ A6(자동 저장)이 들어가면 이 단계 자체가 달라집니다.

## 결정이 필요한 질문 (추천이 맨 앞)

1. **횟수·기간 방식 작업** ("3 times a day"): 시간을 정해 주지 않은 작업은 시터에게 "오늘 3번 중 1번 완료" 카운터 카드로 보여 줌 (추천) / 시간으로 자동 분배.
2. **돌보는 중 요청 규칙**: 열린 요청은 펫당 1건, 시터가 처리하기 전에는 추가 불가 (추천) / 제한 없음.
3. **거절 문구**: 거절 시 시터가 고르는 정중한 사유 칩 — "I can't fit this in today" · "Let's talk first" · "Needs a different time" + 오너에게 "Chloe couldn't take this one — message her to adjust" 표시 (추천). 직접 입력은 선택.
4. **체크인 선택**: 한 번에 하나만 선택 (추천, 단순) / 여러 개 선택 후 한 번에 Send.
5. **탭 활성 표시**: 선택된 탭에 **둥근 알약 배경 + 진한 색 아이콘/라벨 + 살짝 눌린 그림자**(추천) / 위쪽 막대 / 아이콘만 채움.
6. **리마인더 알림**: 화면 전체 **알림 팝업**(소리·진동·Snooze 10 min · Done) + 브라우저 알림 권한 허용 시 탭이 백그라운드여도 알림 (추천). 앱이 꺼져 있을 때의 진짜 알람은 서버 푸시(6.7, 건너뜀)가 필요.
7. **웹캠 촬영**: 컴퓨터에서도 "Take photo"(웹캠) 추가 — 데모 영상 녹화용으로 유용 (추천) / 폰 전용 유지.
8. **폰 카메라 확인**: 머지·배포 후 (추천) / 지금 같은 Wi-Fi 임시 주소로.
