## 📌 문제

펫시터·도그워커를 쓰는 보호자에게는 사진·투약·산책·일일 리포트가 **한곳에 모이는 앱**이 잘 없습니다. 3년간 펫시팅(강아지·고양이)을 하며 매일 본 문제는 이렇습니다.

- **견주는 불안해서** 계속 연락합니다. *"밥 먹었어요?" "약 먹였어요?" "사진 좀 보내주세요"*
- **펫시터는** 메시지 답장, 알림장 작성, 사진 개별 전송에 시간을 뺏깁니다. 정작 돌봄에 써야 할 시간을요.
- **안전 사고가** 틈새로 빠집니다. 빠뜨린 약, 잊은 산책, 숨은 알레르기 성분이 든 간식.

## 💡 우리의 해답

PawNote의 두 가지 약속:

| 견주에게 | 펫시터에게 |
| :--- | :--- |
| **물어볼 필요가 없게.** 사진, 산책, 투약, 알림장이 알아서 도착 | **돌보고, 찍고, 탭만.** 알림장 타이핑도, 같은 질문 답장도 없이 |

## ✨ 기능

### 1. 📸 케어 피드 & 앨범
- 펫시터가 강아지 사진·영상을 **비공개 페이스북형 피드**에 올림 → 개별 전송 불필요
- 새 게시물마다 견주에게 **푸시 알림**, 앨범으로 모아보기
- 견주가 **"사진 요청"** 버튼 한 번 → 펫시터에게 알림
- Nemotron 비전이 사진을 보고 **캡션 자동 작성** → 펫시터는 타이핑 안 함
- 사진·영상은 **Cloudinary**에 저장·자동 압축 (포맷/화질 자동 최적화, 영상 변환)

### 2. 💊 투약 & 산책 의뢰
- 견주가 **약**(이름, 용량, 시간, 주의사항)과 **산책 일정**을 등록
- 정해진 시간에 펫시터에게 **리마인더 알림**
- 펫시터가 **인증 사진** 촬영 → 완료 체크 → 견주에게 즉시 알림
- 놓친 일정은 표시되어 빠뜨리지 않음

### 3. 📝 타이핑 없는 알림장
- 하루가 끝나면 그날의 피드, 완료한 산책·투약, 사진을 바탕으로 Nemotron이 **알림장 초안을 자동 작성**
- 3년치 실제(익명화된) 견주 대화에서 배운 따뜻한 말투
- 펫시터는 확인하고 **탭 한 번으로 전송**

### 4. 🛡️ 간식 세이프티 가드
1. **보기** — 성분표를 찍으면 Nemotron 비전이 읽음
2. **추론** — Nemotron 3 Ultra가 알레르기·견종 금기와 대조, **숨은 성분**까지 (예: "동물성 지방"에 닭고기 포함 가능)
3. **검색** — 모르는 성분이나 리콜 정보는 **Tavily**로 웹 검색
4. **경고** — 급여 전에 경고 모달로 차단

### 5. 📢 펫시터 일정 & 공지사항
- 견주가 펫시터 **일정**(가능 시간, 휴무) 확인
- 펫시터가 올린 **공지**(예: "추석 휴무")가 앱 실행 시 **팝업**으로 표시

### 6. 💬 AI가 먼저 답하는 안심 Q&A
- 개인 연락처 노출 없이 앱 안에서 문의
- 일상적인 질문은 Nemotron이 강아지 프로필과 오늘 기록을 근거로 **펫시터 말투로 먼저 답변**. 필요할 때만 펫시터가 개입

```
18:00  📝 AI가 알림장 초안 작성 → 펫시터 "전송" 탭 → 견주가 퇴근길에 확인
```

## 🟩 NVIDIA Nemotron & Nebius Token Factory 사용 방식

모든 AI 호출은 **Nebius Token Factory**(OpenAI 호환 API)로 실행하고, 작업마다 알맞은 크기의 Nemotron 모델을 씁니다.

| 작업 | 모델 ID | 이유 |
| :--- | :--- | :--- |
| 사진/영상 캡션, 성분표 읽기 | `nvidia/nemotron-3-nano-omni` ¹ | 이미지·영상·텍스트를 한 모델로 |
| 알레르기·숨은 성분 추론 | `nvidia/Nemotron-3-Ultra-550b-a55b` | 안전 판단 → 가장 강한 추론 |
| 알림장 생성 | `nvidia/nemotron-3-super-120b-a12b` | Few-shot 말투 복제 품질 |
| Q&A 1차 답변, 빠른 호출 | `nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B` | 빠르고 저렴 |

¹ Nebius 공식 cookbook에는 있으나 공개 카탈로그엔 없음 → API 키로 `GET /v1/models` 확인 필요

**기타 Nebius 서비스**
- **Nebius AI Cloud — Serverless Endpoint** — **FastAPI 백엔드(API 서버)** 호스팅 (D18)
- **Serverless Jobs** (선택) — 투약 리마인더, 알림장 배치

## 🛠️ 아키텍처

```
[ 견주 앱 ]            [ 펫시터 앱 ]
      └──────────┬──────────┘
                 ▼
   Expo (웹 / iOS / Android)
                 │  REST / JSON · Realtime
                 ▼
        FastAPI (파이썬 백엔드)
          ├── Supabase     → PostgreSQL · 인증 · Realtime(인앱 알림)
          ├── Cloudinary   → 사진/영상 저장, 압축, 썸네일
          ├── Token Factory (Nemotron: Nano Omni / Ultra / Super / Nano)
          ├── Tavily       → 성분·리콜 웹 검색
          └── 스케줄러     → 투약·산책 리마인더
```

| 영역 | 스택 |
| :--- | :--- |
| 프론트엔드 | Expo (React Native for Web) |
| 백엔드 | FastAPI (Python 3.11+) |
| DB / 인증 / 실시간 | Supabase (PostgreSQL) |
| 미디어 | Cloudinary |
| AI | NVIDIA Nemotron @ Nebius Token Factory |
| 웹 검색 | Tavily |
| 알림 | Supabase Realtime (웹) · Expo Notifications (모바일) |
