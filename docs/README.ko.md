## 📌 문제

3년간 펫시팅을 하며 돌봄의 모든 단계에서 같은 문제를 봤습니다.

| 단계 | 지금 일어나는 일 |
| :--- | :--- |
| **문의** | 견주는 **먼저 답한 시터**에게 맡기는 경우가 많습니다. 돌보는 중이거나 자고 있던 시터는 예약을 놓칩니다. |
| **사전 미팅** | 밥·약·집 규칙을 말이나 채팅으로 전하다 보니 빠지는 내용이 생깁니다. |
| **예약** | Lockbox 번호와 집 주소가 필요하기 며칠 전부터 채팅에 그대로 남습니다. 응급 진료 동의는 거의 글로 남기지 않습니다. |
| **돌봄·이동** | 견주는 계속 묻습니다. *"출발하셨어요?" "밥 먹었어요?" "사진 좀 보내주세요"* 시터는 돌봄 대신 타이핑에 시간을 씁니다. |
| **돌봄 후** | 시터가 알게 된 반려동물 정보가 채팅 속에 묻힙니다. 다음 시터는 처음부터 다시 시작합니다. |

## 💡 우리의 해답

| 견주에게 | 펫시터에게 |
| :--- | :--- |
| **물어볼 필요가 없게.** 답장, 이동 소식, 사진, 알림장이 알아서 도착 | **돌보고, 찍고, 탭만.** 견적 계산도, 알림장 작성도, 같은 질문 답장도 없이 |

Goldito는 사람들이 이미 믿고 쓰는 세 가지 경험을 합치고, 타이핑은 AI 에이전트가 맡습니다.

- **Rover**처럼 — 시터 찾기, 문의, 예약
- **키즈노트**처럼 — 투약의뢰서, 등원·하원 체크, 알림장, 사진 앨범
- **Uber**처럼 — 맡기기·찾기마다 실시간 위치와 ETA

## 🔄 Goldito 사용 흐름 — 5단계

```
 ① 문의 ──> ② 사전 미팅 ──> ③ 예약 확정 ──> ④ 돌봄 & 이동 ──> ⑤ 완료
 AI가 1분      케어 의뢰서      동의서·결제·       실시간 이동 · 5초      무사 귀가 · 리뷰 ·
 안에 답장     → 체크리스트     시간 맞춰 해제      체크 · AI 알림장       Pet Life Record → RAG
      ▲                                                                       │
      └──────────── 다음 돌봄은 Goldito가 배운 모든 것과 함께 시작 ──────────────┘
```

### ① 문의 — 시터의 말투로 오는 답
- 견주는 **보딩**(시터 집) 또는 **하우스 시팅**(내 집), 날짜, 반려동물을 고릅니다 — 반려동물 프로필(품종·나이·알레르기)이 함께 전달됩니다.
- **Goldito AI가 몇 초 안에 시터의 말투로 답장 초안을 씁니다.** 시터 캘린더의 가능 여부, **공휴일·다두 할증**이 들어간 견적, 시터 정책과 반려동물 **Life Record**(RAG)를 근거로. 시터가 한 번 탭해 보내거나, 책임 동의 후 자동 발송을 켜면 바쁘거나 자고 있어도 바로 사람 속도로 먼저 답합니다.
- 가격은 모델이 아니라 서버가 계산합니다 — 답장과 결제 화면의 숫자가 항상 같습니다.

### ② 사전 미팅 — 케어 의뢰서가 체크리스트로
- 견주는 메모하듯 **케어·투약 의뢰서**를 씁니다: *"오전 8시 사료 1컵 · 오후 2시 피부약 1알, 간식과 함께 · 노크 금지 — 문자 주세요 · 산책 중 다른 강아지 접근 금지"*
- Nemotron이 이를 시터의 **미션 체크리스트**(시간별 할 일)와 **주의사항** 카드로 정리하고, 견주가 확인한 뒤 저장합니다.
- **처음 맡기는 사이면 먼저 만납니다.** 예약 요청 뒤, 대면이면 서로 미리 적어 둔 장소 중에서 고르고, 영상이면 시간이 정해지는 순간 **Google Meet** 링크와 캘린더 초대가 자동으로 만들어집니다. 한쪽이 건너뛰고 싶으면 상대가 동의해야 하고, 동의하지 않으면 예약이 취소되어 견주는 다른 시터를 찾습니다. 단골이면 이 단계가 없습니다.
- 이동 방식을 고릅니다: **견주가 데려다주기** 또는 **시터가 데리러 가기**.

### ③ 예약 확정 — 동의서, 결제, 그리고 제때 열리는 정보
- 고른 옵션에 맞춰 **캐나다형 동의서**가 자동으로 준비됩니다: 24시간 응급 동물병원 진료 승인, Lockbox·콘도 Buzzer·Fob 사용, 합사, 귀가 규칙.
- **결제** (데모에서는 가상 결제 — 카드 불필요).
- **시간 맞춰 해제:** 보딩이면 결제 즉시 시터 집 주소·방문자 주차·짐 체크리스트가 열립니다. 견주 집 출입 정보(Lockbox 번호·Buzzer)는 **방문 2시간 전에만** 시터에게 열리고, 열리는 순간 견주에게 알림이 갑니다.

### ④ 돌봄 & 이동 — 실시간 이동, 5초 체크, AI 알림장
- **Uber식 이동:** 운전하는 쪽이 **Start trip**을 누르면 상대방은 실시간 지도와 ETA를 봅니다. 도착하면 견주에게는 방문자 주차 안내, 시터에게는 Buzzer·Lockbox 카드가 뜹니다.
- **사진 체크인:** 인계 순간 사진 한 장 → 비전 모델이 반려동물이 있는지, 차 안에서 크레이트·안전벨트로 고정됐는지 확인 → 견주에게 *"Pick-up complete — care has started · photo verified"*
- **5초 체크:** 하루 기록과 사진에서 AI가 칩을 제안합니다 — 식사 ✅ · 배변 ✅ · 산책 20분 ✅ · 투약 ✅ · 🐿️ 공원 다람쥐. 시터는 틀린 칩을 끄고 필요하면 짧게 적기만 하면 **Nemotron이 그 내용만으로 시터의 말투로 알림장을 쓰고**, 시터가 승인하면 게시됩니다.
- **타임라인 앨범:** 사진마다 AI 캡션 + 날짜별 식사·산책·낮잠 분류 (키즈노트 앨범처럼)
- **간식 세이프티 가드** *(stretch)*: 성분표를 찍으면 Nemotron Ultra가 알레르기·숨은 성분(예: "동물성 지방" 속 닭고기)을 급여 전에 잡아냅니다.

> *"Max took the skin pill you left, tucked inside her treat, and finished every bit of her kibble! On our 20-minute morning walk she spotted a squirrel in the park and got so excited — it was adorable. Her potty was perfectly healthy, too. 🐶"*
> — 칩 몇 개, 사진 2장, 시터의 짧은 한 줄로 만든 AI 알림장 (앱 출력은 영어, D1)

### ⑤ 완료 — 무사 귀가, 그리고 기억하는 기록
- 마지막 인계는 사진과 함께 *"Max is home safe 🏠"* 리포트로 끝나고, 감사 인사와 **★ 5점 리뷰** 요청이 갑니다.
- Nemotron이 이번 돌봄 전체(체크인·할 일·알림장·인계 사진 확인)를 반려동물의 **Life Record**로 정리합니다: 식습관, 배변 특성, 약 반응, 행동, 주의사항.
- Life Record는 **RAG 지식 베이스**에 저장됩니다. 다음 예약에서는 **새 시터여도** AI 답장, 체크리스트, 시터 요청 카드가 이미 그 반려동물을 알고 있습니다.

## 🤖 Goldito 에이전트

Goldito의 AI는 에이전트처럼 움직입니다. 돌봄 중 일이 생기면 스스로 필요한 사실을 모아 행동하고 기억하며, 상대에게 닿는 것은 모두 사람이 승인합니다.

| 이런 일이 생기면 | 에이전트가 하는 일 | 사람이 정하는 것 |
| :--- | :--- | :--- |
| 견주가 문의 | 캘린더 확인, 서버 견적, Life Record 검색, 시터 말투로 답장 초안 | 시터가 **Send** (또는 자동 발송을 켬) |
| 견주가 케어 의뢰서 작성 | 시간별 할 일과 주의사항 카드로 정리 | 견주가 확인 후 저장 |
| 인계 사진 촬영 | 반려동물이 있는지, 차 안에서 고정됐는지 확인 | 조언만 — 시터는 계속 진행 가능 |
| 하루가 끝나면 | 기록과 사진에서 칩 제안 → 알림장 작성 | 시터가 칩 수정·한 줄 추가·승인 |
| 돌봄이 끝나면 | Life Record 작성 → 다음을 위해 인덱싱 | 견주가 읽음 |
| 다음 문의가 오면 | 그 Life Record를 찾아 새 시터도 알고 시작 | — |

가격·날짜·출입 코드는 모델이 만들지 않습니다. 서버가 주고, 에이전트는 그 주변 문장만 씁니다.

## 🗓️ Goldito와 함께하는 한 번의 돌봄 (데모 경로)

추수감사절 연휴: 로버트가 **맥스**(강아지·말티즈·닭고기 알레르기)와 **모찌**(고양이)를 시터 클로이에게 맡깁니다.

```
월 22:40  ① 로버트가 10/9–12 문의 (클로이는 자동 발송 모드) → 입력 중 → 약 30초 뒤 답장: 가능, 추수감사절·두 번째 반려동물 요금 포함 총액,
             "맥스는 약을 간식에 넣어 주면 잘 먹는다고 기록돼 있어요 — 그렇게 할게요"
화        ② 예약 요청 → 케어 의뢰서 → AI 체크리스트 → 첫 만남이라 영상 Meet & Greet (Google Meet 링크·캘린더 초대)
             → 맡기기: 시터가 데리러 감, 찾기: 견주가 데리러 감
수        ③ 클로이 수락 → 로버트 동의서 5개 서명 → 결제(데모) → 클로이 집 주소·방문자 주차 해제
금 05:30     픽업 2시간 전 클로이에게 출입 정보 해제 → 로버트에게 알림
금 07:30  ④ 클로이 Start trip (위치 공유 동의 화면에서 Allow) → 로버트가 ETA 확인 → 도착 시 Buzzer·Lockbox 카드
             → 차 안 크레이트 사진 → ✅ "Pick-up complete — care has started"
금 18:00     하루 기록·사진 2장 → AI 칩 제안 → 클로이가 한 줄 추가 → AI 알림장 → 클로이 승인 → 게시
             · 앨범이 식사·산책·낮잠으로 정리
월 17:00  ⑤ 로버트 출발(클로이가 ETA 확인) → 방문자 주차 카드 → 귀가 사진
             → "Max and Mochi are home safe 🏠" → ★★★★★ → 다음 시터를 위한 Life Record 갱신
```

컴퓨터에서는 폰 프레임 안에서 돌아갑니다 — **클릭 = 탭, 드래그·스크롤 = 스와이프**. 샘플 사진과 **Simulate the drive** 버튼이 내장돼 있어 카메라·GPS 없이도 전부 재현됩니다.

## 🟩 NVIDIA Nemotron & Nebius Token Factory 사용 방식

모든 AI 호출은 백엔드에서 **Nebius Token Factory**(OpenAI 호환 API)로 실행합니다. 추론·글쓰기는 NVIDIA Nemotron, 사진은 Token Factory 비전 모델, 검색은 Token Factory 임베딩 모델이 맡습니다. 역할별 모델 ID: [model-ids.md](plan/phases/notes/model-ids.md).

| 단계 | AI 작업 | 모델 ID | 이유 |
| :--- | :--- | :--- | :--- |
| ① 문의 | 시터 캘린더·서버 견적·정책·Life Record 근거 자동 답장 | `nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B` | 몇 초 안에 답할 속도, 사실·가격은 서버가 제공 |
| ① ⑤ 검색 | RAG 지식 베이스 임베딩 (Life Record·정책·지난 문의) | `Qwen/Qwen3-Embedding-8B` (1024차원) | Token Factory의 임베딩 모델, Supabase pgvector에 저장 |
| ② 사전 미팅 | 케어·투약 의뢰서 → 미션 체크리스트 | `nvidia/nemotron-3-super-120b-a12b` | 시각·용량·주의사항 구조화 신뢰도 |
| ④ 이동 | 인계 사진 확인 — 반려동물, 차 안 크레이트·안전벨트 | `openbmb/MiniCPM-V-4_5` ¹ | Token Factory 비전 모델 |
| ④ 돌봄 | 사진 묘사 → 5초 체크 기반 알림장 | `openbmb/MiniCPM-V-4_5` → `nvidia/nemotron-3-super-120b-a12b` | 3년치(익명화) 실제 알림장 few-shot 말투 |
| ④ 앨범 | 캡션 + 분류 (식사·산책·낮잠·놀이) | `openbmb/MiniCPM-V-4_5` | 사진 1장 = 호출 1번, 시터 타이핑 없음 |
| ④ 간식 가드 *(stretch)* | 알레르기·숨은 성분 추론 | `nvidia/Nemotron-3-Ultra-550b-a55b` | 안전 판단 → 가장 강한 추론 |
| ⑤ 완료 | 돌봄 → Pet Life Record (식습관·배변·약·행동·주의사항) | `nvidia/nemotron-3-super-120b-a12b` | 기록된 사실만 쓰는 긴 맥락 요약 |

¹ Token Factory의 NVIDIA 비전 모델(`Nemotron-Nano-V2-12b`·`Cosmos3-Super-Reasoner`·`Nemotron-3-Nano-Omni`)은 Dedicated Endpoint 전용이라 공용 API로 부를 수 없고(2026-10-02 확인), 심사 기간 내내 켜 두면 크레딧을 넘음 → 비전은 공용 API의 MiniCPM-V-4.5. 시나리오 원문의 Qwen-2.5-VL은 카탈로그에 없음. 추론·글쓰기·답장은 Nemotron.

**기타 Nebius 서비스**
- **Nebius AI Cloud — Serverless Endpoint** — FastAPI 백엔드 호스팅 (Render는 긴급 fallback만)
- **Serverless Jobs** (계획) — 리마인더, 저녁 알림장 초안

## 🔐 설계부터 지킨 프라이버시·안전

- **출입 정보는 제때만.** Lockbox·Buzzer 코드는 예약된 시터에게만, 방문 2시간 전부터 돌봄 종료까지 보이고, 열릴 때 견주에게 알림이 갑니다. AI 프롬프트와 RAG에는 절대 들어가지 않습니다.
- **위치는 이동 중에만.** 예약 상대방에게만 현재 위치 하나를 공유하고, 도착하면 멈춥니다. 경로 기록은 저장하지 않습니다.
- **영상 Meet & Greet는 Google Meet로.** 캘린더 초대를 보내기 위해 견주·시터의 계정 이메일만 Google에 전달합니다.
- **AI는 사실을 지어내지 않습니다.** 가격·날짜·가능 여부는 DB에서, 알림장과 Life Record는 그날 기록된 것만으로.
- **실제 개인정보 없음.** 데모 계정·반려동물·주소·코드는 모두 가상이고, 말투 학습용 실제 메시지는 프롬프트에 쓰기 전에 익명화합니다.

## 🛠️ 아키텍처

```
[ 견주 앱 ]            [ 펫시터 앱 ]
      └──────────┬──────────┘
                 ▼
   Expo (웹 / iOS / Android) — 데스크톱 브라우저에서는 폰 프레임
                 │  REST / JSON · Realtime (알림, 실시간 이동)
                 ▼
        FastAPI (파이썬 백엔드)
          ├── Supabase     → PostgreSQL + RLS · 인증 · Realtime · pgvector (RAG)
          ├── Cloudinary   → 사진/영상 저장, 압축, 썸네일
          ├── Token Factory (Nemotron Nano·Super·Ultra · MiniCPM-V · Qwen3 Embedding)
          ├── Google Calendar → 영상 Meet & Greet용 Google Meet 링크·초대
          ├── OpenStreetMap → 이동 지도 (보기 전용)
          └── Tavily       → 성분·리콜 웹 검색 (세이프티 stretch)
```

| 영역 | 스택 |
| :--- | :--- |
| 프론트엔드 | Expo (React Native for Web) |
| 백엔드 | FastAPI (Python 3.12) |
| DB / 인증 / 실시간 / 벡터 검색 | Supabase (PostgreSQL, RLS, pgvector) |
| 미디어 | Cloudinary |
| AI | NVIDIA Nemotron + MiniCPM-V(비전) + Qwen3 Embedding @ Nebius Token Factory |
| 지도 | Leaflet + OpenStreetMap |
| 영상 Meet & Greet | Google Meet (Google Calendar API) |
| 웹 검색 | Tavily |
| 알림 | Supabase Realtime 인앱 알림 (웹 데모) · Expo 푸시 (네이티브 앱, 해커톤 후) |
