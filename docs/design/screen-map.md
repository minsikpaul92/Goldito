> How to use it (DESIGN.md §0): find a Figma frame's screen by its route, or a button by its label, then open the file at the line.
> **ID** is the stable name of an action (`testID`): the e2e tests and analytics use it, so moving a button keeps its ID, merging two buttons keeps one ID, and removing a button removes its ID from the tests too.
