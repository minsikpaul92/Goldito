   Token Factory에서 확인된 NVIDIA 모델: [개발 계획 § AI 모델](../plan/README.ko.md#6-ai-모델-2026-09-28-웹에서-확인)

## 5. 심사 기준 (2차, 4개 항목 동일 비중)

| 기준 | 심사위원이 보는 것 |
| :--- | :--- |
| **기술 구현** | 얼마나 잘 만들었고, Token Factory와 Nemotron을 얼마나 효과적으로 썼나 |
| **디자인** | 기술 데모가 아니라 완성된, 일관된 제품 경험인가 → **묵 님 역할이 점수에 직결** |
| **잠재적 임팩트** | 실제 사용자의 구체적 문제를 설득력 있게 제시하고, 데모가 실제로 해결하나 |
| **아이디어 품질** | Nemotron을 창의적이고 뻔하지 않게 썼나, 문제 영역을 진짜 이해하나 |

동점이면 위 순서(기술 구현 먼저)로 비교합니다.
**심사위원은 앱을 직접 안 써보고 설명·이미지·영상만으로 심사할 수 있음** → 영상과 설명의 완성도가 매우 중요.

## 9. 주최 측 팁 (Updates)

- **피드백은 필수이자 채점 대상.** Token Factory, AI Cloud, 각 NVIDIA 모델마다: 어디에 썼는지, 좋았던 점, 개선할 점, 온보딩 경험(0 → hello world), 다시 쓸지와 이유. "문서가 헷갈렸다"처럼 모호하게 쓰지 말고 도구 이름을 명시.
- **뻔한 수준을 넘어서라.** 기본 기능 이상을 보여줘야 함.
- **프로젝트 이름은 사람처럼 친근하게.**
- **작업에 맞는 모델 선택** — 비전, 추론, 빠른 호출마다 모델을 바꿔 쓰는 것을 권장.
